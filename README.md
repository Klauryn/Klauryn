## About Me

I'm an automation engineer with 4+ years of experience in industrial automation software. I work across the whole chain: PLC logic, communication between devices, and the desktop interfaces operators and engineers use to see what a machine is doing.

Most of my work is on Siemens S7-1200/1500 controllers (TIA Portal), with interfaces written in C#.

My focus areas:

* **PLC programming:** Siemens TIA Portal (Structured Text, Ladder, FBD), Beckhoff basics
* **Desktop & HMI software:** C# WinForms and WPF (MVVM, ReactiveUI)
* **Industrial communication:** Modbus TCP/IP, S7Net, OPC-UA, two-way PLC ↔ PC data exchange
* **Data & MES integration:** MSSQL, .NET Entity Framework Core
* **Robotics:** ABB IRB robots (RAPID, RobotStudio)
* **Field work:** machine commissioning, sensors, servo, hydraulic and pneumatic systems

I care about interfaces that make faults easy to find. In one project, detailed error logging and instant alerts cut fault detection and diagnosis time by about 3x.
